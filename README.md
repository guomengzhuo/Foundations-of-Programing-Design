## Course Overview

Programming is not only about learning the syntax of a programming language. More importantly, it is about learning how to **translate a problem into a sequence of logical and executable steps**.

This course uses **Python** as the primary programming language. We will gradually move from basic programming concepts to more structured approaches to problem solving and program design.

The course is intended to help students develop three closely related abilities:

1. **Programming fundamentals**  
   Understand Python syntax, variables, data types, expressions, control structures, functions, and other fundamental programming concepts.

2. **Computational thinking**  
   Learn how to decompose a problem, identify its logical structure, design an algorithm, and translate the solution into executable code.

3. **Program design**  
   Learn how to write programs that are not only correct, but also clear, structured, reusable, and easy to understand.

No extensive prior programming experience is required. The materials are organized to support students who are learning programming step by step.

## Recommended Learning Workflow

Programming is best learned through a combination of **reading, understanding, coding, debugging, and practice**.

A recommended workflow is:

### Before Class

- Briefly review the upcoming lecture slides if available.
- Read the assigned or recommended supplementary materials.
- Make note of concepts or terminology that are unfamiliar.

### During Class

- Focus on understanding **why** a program is written in a particular way rather than simply copying the code.
- Follow the execution process of each example.
- Try to predict program outputs before running the code.
- Pay attention to common mistakes and debugging examples.

### After Class

- Reproduce the examples independently.
- Modify the examples and observe how the program behavior changes.
- Complete the assigned exercises.
- Review supplementary reading materials when a concept is unclear.
- Try to explain the logic of your program in plain language before writing the code.

A useful principle throughout the course is:

> **Do not only ask, "What code should I write?"**  
> First ask, **"What problem am I solving, and what are the logical steps needed to solve it?"**

## Learning Programming

Learning programming requires practice.

Reading code can help you understand an idea, but being able to read a program is different from being able to write one yourself. Whenever possible, you should run the examples, modify them, make mistakes, debug them, and try to solve similar problems independently.

When studying an example, consider the following questions:

- What problem is this program trying to solve?
- What are the inputs and expected outputs?
- What information needs to be stored?
- What decisions need to be made?
- What operations need to be repeated?
- How is the problem divided into smaller parts?
- Can the solution be made clearer or more reusable?
- What happens if the input or assumptions change?

The goal of this course is not simply to remember Python syntax, but to gradually develop the ability to **design solutions and express them through programs**.
